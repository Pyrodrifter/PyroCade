# PyroCade identity

An original flame silhouette with a play button cut out of its centre. The app icon places the ember mark on a rounded graphite glass tile. The standalone mark and wordmark have transparent backgrounds.

- `pyrocade-mark.svg` / `.png`: full-colour mark.
- `pyrocade-mark-mono.svg`: single-colour version using `currentColor`.
- `pyrocade-icon.svg`: scalable glass app icon.
- `pyrocade-icon-{size}.png`: 16, 24, 32, 48, 64, 128, 256, 512 and 1024px icons.
- `pyrocade.ico`: 16–256px Windows icon with seven sizes.
- `pyrocade-wordmark.svg` / `.png`: transparent horizontal lockup.
- `pyrocade-banner.svg` / `.png`: repository banner.
- `brand.js`: generated theme-adaptive header mark.

Source and exports are produced by `npm run brand:build` using the project's Electron runtime. No image-generation service or external icon/font asset is required. The original vector paths and exported assets are covered by the repository's MIT license.
